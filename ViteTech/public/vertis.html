Vite Vertis · Geometry

Dense geometry without a virtualised pipeline.

Vite Vertis is Vite's geometry system: high-quality level-of-detail chains generated at import, with continuous, pop-free transitions between them, rendered through the standard mesh pipeline. It is built to beat Nanite on the hardware games actually ship on.

The approach Talk to the team

The problem

Virtualised geometry has a base cost every frame.

Nanite moves geometry onto its own pipeline — streaming, a visibility buffer and a dedicated rasteriser — and a project pays for that machinery before it draws anything. On high-end PCs the trade can pay off. On console-class and handheld hardware, with native resolution and 60 or 120 FPS targets, that base cost is budget a game cannot spare.

Classic discrete LODs avoid the base cost but pop visibly as they switch, which is why teams either over-spend on LOD 0 or accept the artefact.

The approach

Do the hard work at import. Keep the runtime simple.

Vertis generates each mesh's level-of-detail chain at import with a high-quality, attribute-aware simplifier, and bakes the data needed to blend smoothly from one level to the next. At runtime, transitions are continuous rather than discrete, so detail falls away without popping.

Rendering stays on the standard static-mesh path, so Vertis meshes keep working with everything static meshes already support in Vite.

Design goals

What Vertis is built to deliver

Pop-free transitions

Continuous blending between levels of detail, so reducing detail never shows up as a visible switch.

High-quality simplification

Attribute-aware simplification at import keeps silhouettes, UVs and normals intact down the LOD chain.

No fixed base cost

No visibility buffer, no separate rasteriser and no streaming system to run every frame. Cost follows what is drawn.

Standard pipeline

Instancing, shadows, ray tracing and existing materials keep working, because the mesh is still a static mesh.

Platform reach

Runs wherever Unreal Engine 4 static meshes run, without requiring newer GPU features to light up.

Editor-time bake

Generation happens when assets are built, so artists keep the familiar LOD workflow and runtime pays nothing to build it.

Status: in development. Vertis builds on Vite's existing static-mesh LOD pipeline and on the distance- and displacement-driven tessellation that ships today. Performance comparisons will be published with the first release, measured with the same methodology as Vite's other benchmarks.
