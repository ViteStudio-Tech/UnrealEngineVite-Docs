The suite

Five technologies. One rule: it has to ship.

Each technology is developed inside a production engine, against fixed frame budgets and console-class CPUs, and measured before it is claimed.

Global illumination · Path tracing

Vite ReSTIR

Reservoir-based spatiotemporal resampling for real-time global illumination, with a real-time path tracer on the same pipeline. Path-traced lighting designed to cost less than Lumen at Epic quality.

Vite ReSTIR

Physics SDK · CPU and GPU

ViteX Physics

A physics SDK fully compatible with Unreal Engine 4, combining solver advances from PhysX 4 and 5 tuned for games with GPU-accelerated fluids, cloth and smoke through Flex and Flow.

ViteX Physics

Shading

A character-grade BRDF based on Callisto: dual-lobe specular, smooth terminator, retroreflection and diffuse Fresnel.

How we build

Engineering principles

{{icon:target}}

Native resolution first

Image clarity degrades first and is hardest to win back. Budgets go to holding native resolution, not to reconstructing it.

{{icon:gauge}}

Fixed frame budgets

Every feature is costed in milliseconds against 60 and 120 FPS targets before it is enabled by default.

{{icon:cpu}}

Console-class CPUs

Physics and animation kernels are timed on PS5-class silicon, with one 256-bit FMA pipe, not on desktop parts.

{{icon:switch}}

Pay only for what you use

Optional systems compile out by default. Gating extra shading models alone raised a reference scene by 12.3%.

{{icon:shield}}

Production-proven

Features must survive cooking, packaging and shipping on real hardware. Demos are a by-product, not the goal.

{{icon:eye}}

Reproducible numbers

Results are published with host, build, workload and thread counts, so they can be checked rather than taken on trust.
