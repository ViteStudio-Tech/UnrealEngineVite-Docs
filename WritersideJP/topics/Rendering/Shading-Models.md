# シェーディングモデル

<tldr>
<p>
Vite は標準の 4.27 のシェーディングモデルに 3 つを追加しています。高品質な肌やキャラクターのサーフェス向けの
<b>Callisto BRDF</b>、スタイライズドな非写実的レンダリング向けの <b>Toon</b>、そして <b>Lit Reactive</b> です。いずれも既存のマテリアルのピンを流用するため、作成前にピンの対応表を確認してください。
</p>
<p>
July Major 以降、<b>Callisto BRDF と Toon は既定でコンパイル対象から外れています</b>。使うには
<code>VITE_SHADINGMODEL_CALLISTO=1</code> または <code>VITE_SHADINGMODEL_TOON=1</code> でビルドしてください。
<a href="Compile-Time-Switches.md">コンパイル時スイッチ</a> を参照してください。
</p>
</tldr>

シェーディングモデルは、マテリアルの詳細パネルの **Shading Model** ドロップダウンで選ぶか、**Shading Model** のマテリアル式でピクセルごとに指定します。標準の Unreal Engine 4.27 のシェーディングモデルはすべて引き続き利用できます。

## 追加されたシェーディングモデル

| シェーディングモデル | 表示名 | 用途 |
|---|---|---|
| `MSM_CallistoBRDF` | Callisto BRDF | 単一または 2 ローブの GGX スペキュラーによる、高品質なキャラクターと肌のサーフェス |
| `MSM_Toon` | Toon | Guilty Gear に着想を得た、スタイライズドなセルシェーディング |
| `MSM_LitReactive` | Lit Reactive | 異方性とタンジェントに対応した Lit サーフェスの派生 |

## Callisto BRDF

Callisto BRDF は、スペキュラーのフレネルの減衰を備えた単一または 2 ローブの GGX スペキュラーを提供します。既定の
Lit モデルの単一のスペキュラーローブでは粗すぎる、キャラクターや肌を対象としています。[Callisto BRDF のデモプロジェクト](Callisto-BRDF-Demos.md) で、男性と女性のキャラクターのサーフェスに適用した例を確認できます。

### ピンの対応

このモデルは標準のマテリアルのピンをいくつか流用します。シェーディングモデルを選ぶとマテリアルエディタが自動的にラベルを付け替えますが、マテリアルグラフを読んだりマテリアル関数を書いたりする際は、対応を知っておくと役立ちます。

| 標準のピン | Callisto BRDF でのラベル | 用途 |
|---|---|---|
| Opacity | **Retroreflection** | 再帰反射の応答の強さ |
| Ambient Occlusion | **Retroreflection Falloff** | 再帰反射の項の減衰カーブ |
| Anisotropy | **Diffuse Fresnel** | ディフューズのフレネル項 |
| Custom Data 0 | **Smooth Terminator** | 影の境界をまたぐ光のターミネーターを和らげる |
| Custom Data 1 | **Diffuse Fresnel Falloff** | ディフューズのフレネル項の減衰カーブ |

### Callisto Advanced Params

標準のピンに収まらないパラメーターは、追加のカスタム出力ノード **Callisto Advanced Params** で公開しています。

| 入力 | 用途 |
|---|---|
| Specular Fresnel Falloff | スペキュラーのフレネルの応答の減衰カーブ |

他のカスタム出力と同じようにマテリアルグラフにノードを追加します。これは `CallistoAdvancedParams` マテリアル関数にコンパイルされます。

### 作成時の注意点

最も理解しておく価値があるのは、スムーズターミネーターの制御です。標準の GGX シェーディングが生む硬い光のターミネーターは、有機的な曲面、特にかすめる角度から照らされた顔で、シェーディングの境界が不自然に鋭く見えるというよく知られたアーティファクトです。スムーズターミネーターの入力は、全体のシェーディングを平坦にすることなく、この遷移を和らげます。

再帰反射とディフューズのフレネルの制御を組み合わせると、肌、細かな繊維の布、ほこりをかぶった表面など、かすめる角度に向かって明るくなるサーフェスを、サブサーフェスのモデルに頼らずに表現できます。

## Toon

Toon シェーディングモデルは、Arc System Works による Guilty Gear の手法に着想を得たセルシェーディングで、シェーディングのランプ、スペキュラーの形状、影色をアーティストが明示的に制御できます。

### ピンの対応

PBR の標準的なパラメーターの多くはセルシェーディングでは意味を持たないため、Toon は他のどのモデルよりも多くのピンを流用します。

| 標準のピン | Toon でのラベル | 用途 |
|---|---|---|
| Metallic | **Specular Brightness** | スペキュラーのハイライトの強さ |
| Specular | **Specular Size** | スペキュラーのハイライトの大きさ |
| Roughness | **Shadow Bias** | 明部と暗部の境界のしきい値をずらす |
| Anisotropy | **Softness** | 明部と暗部の遷移の柔らかさ |
| Subsurface Color | **Shaded Color** | 暗部で使う明示的な色 |

**Shaded Color** が鍵となる制御です。ベースカラーを暗くして影色を導くのではなく直接指定するため、セルシェーディングのアートに特有の、物理的ではない影の色の変化（たとえば濃い茶色ではなく紫になる肌）を表現できます。

**Shadow Bias** と **Softness** が合わさってランプを決めます。バイアスを中央付近にしてソフトネスをほぼ 0 にするとくっきりした 2 トーンになり、ソフトネスを上げるとグラデーションに近づきます。

## Lit Reactive

異方性、タンジェントの入力、Custom Data 0 に対応した Lit サーフェスの派生です。不透明度とオパシティマスクの最適化パスでは、Default Lit と同じく基本的な不透明サーフェスとして扱われるため、他の Lit モデルが引き起こすマスクや半透明専用の属性のコンパイルを避けられます。[June Major](ueVite26-JuneMajor.md) で、FSR のリアクティブマスク向けに静的な WPO のベロシティを出力する目的で追加されました。

## シェーダーパーミュテーション

使用中のシェーディングモデルごとにシェーダーパーミュテーションが増え、コンパイル時間、PSO の数、ディスク容量を消費します。これは理論上の懸念ではなく実際の予算です。パーミュテーションの増加は、[UE4 と UE5 のコスト分析](UE4-Versus-UE5-Cost-Analysis.md)
で説明しているように、Vite が避けるために存在する劣化の 1 つです。追加のシェーディングモデルを既定で外すことで、基準シーンのフレームレートは 12.3% 向上しました。

> アートディレクションに必要な最小限のシェーディングモデルを使ってください。Default Lit とキャラクター用の
> Callisto BRDF だけを使うプロジェクトは、マテリアルライブラリ全体で 6 つのモデルを使うプロジェクトより、コンパイルが
> 速く、PSO が少なく、読み込みも速くなります。
>
{style="note"}

Vite がパーミュテーションをどう管理しているかは [シェーダーコンパイルと PSO](Shader-Compilation-And-PSO.md) を参照してください。また、Shipping 構成では実行時の PSO がデブロートされます。
