# カラーマネジメント

<tldr>
<p>
Vite は Unreal Engine 4.27 のトーンマッピングと色のパイプライン（ACES のフィルムトーンマッパー、ポストプロセスボリュームでのグレーディング、LUT、HDR 出力）をベースに、3 つの追加を加えています。ACES 1.3.1 のガマット圧縮、UE 5.7 のリファレンスに合わせた色再現、そして UE 5.0 のローカル露出です。このページでは、その制御と、最も問題を起こしやすい設定を説明します。
</p>
</tldr>

カラーマネジメントはフレームの最後の段階であり、[ライティング](Global-Illumination.md) と [レイトレーシング](Ray-Tracing.md)
のシステムが行ったすべての作業が、正しい見た目でディスプレイに届くかどうかを決めます。

## パイプライン

レンダラーは全体を通してリニアな HDR で動作します。フレームの最後に次の処理を行います。

1. **[SMAA](Anti-Aliasing.md)** が、トーンマッピングの前にリニア空間でエッジを解消します。
2. **カラーグレーディング** が、ポストプロセスボリュームの露出、ホワイトバランス、彩度、コントラスト、ゲイン、ガンマ、オフセットの制御と、カラーグレーディングの LUT を適用します。
3. **トーンマッピング** が、ACES のフィルミックカーブで HDR の範囲をディスプレイの範囲に変換します。
4. **出力のエンコード** が、対象ディスプレイの伝達関数（SDR では sRGB、HDR では PQ/ST-2084）を適用します。

## Vite での変更点

| リリース | 変更内容 |
|---|---|
| [LTS](ueVite25-LTS.md) | ACES 1.3.1 のガマット圧縮。色域外の色（彩度の高いエミッシブ、レーザー、ネオン）をクリップせずに滑らかに範囲内へ戻します |
| [March Major](ueVite26-MarchMajor.md) | 色再現を UE 5.7 のリファレンスに合わせて更新し、UE5 でグレーディングしたコンテンツが Vite でも同じに見えるように |
| [August Major](ueVite26-AugustMajor.md) | `VITE_UE5_POSTPROCESSING`（既定で有効）による、UE 5.0 のローカル露出のパス、ポストプロセス設定、ヒストグラムのパス |

ローカル露出は、全体のコントラストを平坦にすることなく、フレームのダイナミックレンジを局所的に圧縮し、明るい窓と暗い屋内のディテールを同時に保ちます。その設定は、既存の露出の制御と並んでポストプロセスボリュームに表示されます。コンパイル対象から外す方法は [コンパイル時スイッチ](Compile-Time-Switches.md) を参照してください。

## トーンマッパーの制御

| CVar | 既定値 | 用途 |
|---|---|---|
| `r.TonemapperFilm` | `1` | ACES のフィルムトーンマッパーを使用。`0` で従来のカーブに戻ります。 |
| `r.Tonemapper.Quality` | `5` | `0` は基本のみ、`1` はフィルムコントラストを追加、`2` はビネットを追加、`3` はフィルムのシャドウの色味を追加、`4` はグレインを追加、`5` はグレインのジッターを追加（最高品質） |
| `r.Tonemapper.Sharpen` | `0` | トーンマッパーでのシャープニング。上限は 10。`0.5` は半分、`1` は最大の強さ。 |
| `r.Tonemapper.GrainQuantization` | `1` | `1` は 8 ビットの色の量子化に対抗するため高周波のピクセルパターンを加えます。`0` はわずかに高速です。 |
| `r.TonemapperGamma` | `0.0` | `0` は既定の sRGB または Rec709 の変換を使用し、それ以外の値は固定のガンマを強制します。 |
| `r.Gamma` | `1.0` | 出力時に適用するガンマ |

`r.Tonemapper.Quality` は本物のスケーラビリティの調整項目です。1 段階下げるごとにトーンマッパーのシェーダーから機能が
1 つ取り除かれ、より安価なパーミュテーションになります。ビネット、フィルムのシャドウの色味、グレインを使わないプロジェクトでは、品質レベルを下げても見た目に影響はなく、フレームタイムとシェーダーパーミュテーションの両方を節約できます。

`r.Tonemapper.Sharpen` には注意が必要です。トーンマッパーで少しシャープにすると知覚されるソフトさを補えますが、[アンチエイリアシング](Anti-Aliasing.md) の後に働くため、SMAA が解消したばかりのエッジにエイリアシングを再び持ち込みます。画像がソフトに見える場合は、まず実際にネイティブ解像度で描画していて、アップスケーラーが動作していないことを確認してください。

## カラーグレーディング

グレーディングはすべて、ポストプロセスボリュームの **Color Grading** で行います。制御は Temperature、Global、Shadows、Midtones、Highlights に分かれ、それぞれに彩度、コントラスト、ガンマ、ゲイン、オフセットがあります。

Unreal のグレーディングは、トーンマッピングの前にリニア空間で適用されます。2D の画像編集ソフトで正しく見えるグレーディングの値がそのまま使えないのはこのためで、ディスプレイ基準のピクセルではなく、シーン基準のリニアなデータをグレーディングしているのです。

**LUT。** カラーグレーディングの LUT は、ブレンドの重みとともにポストプロセスボリュームに割り当てられます。すでにグレーディングしたキャプチャではなく、シーンのニュートラルなキャプチャを基準に LUT を作成してください。そうしないとグレーディングが重なってしまいます。

## HDR 出力

| CVar | 用途 |
|---|---|
| `r.AllowHDR` | プロジェクトで HDR 出力のサポートを有効化。通常はプロジェクトごと、またはプラットフォームごとに `DefaultEngine.ini` で設定します。 |
| `r.HDR.Display.OutputDevice` | 出力の伝達関数を選択 |
| `r.HDR.Display.ColorGamut` | 出力の色域を選択 |

```ini
; Config/DefaultEngine.ini
[/Script/Engine.RendererSettings]
r.AllowHDR=1
```

Vite では [SMAA がトーンマッピングの前に実行される](Anti-Aliasing.md) ため、HDR 出力と SMAA は正しく組み合わさります。トーンマッパーの後に実行されるアンチエイリアシングの実装は、一般に HDR 出力のために作り直す必要がありますが、この実装はその必要がありません。

Slate と UI は `r.TonemapperGamma` を通じて出力デバイスを考慮して合成されますが、SDR を基準に作成した UI は HDR では不自然に見えます。そのまま使えると想定せず、HDR で UI を確認する時間を確保してください。

## よくある問題

<deflist>
<def title="シーンが白っぽく、ミルクがかったように見える">
通常はグレーディングの問題ではなく、環境光やフォグが強すぎることが原因です。<a href="Ambient-Occlusion.md">AO</a> が適用されているか、<a href="Global-Illumination.md">GI</a> の強度が高すぎないかを確認してください。グレーディングでコントラストを上げる前に、<a href="Path-Tracing.md">パストレーシング</a> のリファレンスと比較してください。
</def>
<def title="エディタのビューポートとパッケージ化したビルドで色が変わる">
ほとんどの場合、出力デバイスが異なるか、範囲が限定されていないポストプロセスボリュームが原因です。両方で
<code>r.HDR.Display.OutputDevice</code> が一致していることを確認し、エディタ専用のポストプロセスボリュームがないか調べてください。
</def>
<def title="グラデーションや空にバンディングが出る">
<code>r.Tonemapper.GrainQuantization</code> が <code>1</code> であることを確認してください。HDR ディスプレイでバンディングが残る場合は、元のグラデーション自体が量子化されている可能性があります。空のテクスチャやグラデーションのマテリアルの精度を確認してください。
</def>
<def title="エディタでは鮮明なのにゲームではソフトになる">
アップスケーラーが動作していないことを確認してください。<a href="Upscalers.md">アップスケーラー</a> を参照してください。Vite は既定でネイティブ解像度で描画するため、通常の原因はゲームの設定メニューで有効にしたアップスケーラーです。
</def>
</deflist>
