# Vite の概要

<tldr>
<p>
Vite は NVIDIA の NvRTX Caustics ブランチをベースとした、製品開発向けの Unreal Engine 4.27 フォークです。PhysX 3.4 と、特定のライティング手法に依存しないレイトレーシングパイプラインを維持し、Epic の UE5 機能群（Lumen、Nanite、VSM、TSR、Chaos）を、高フレームレートでネイティブ解像度を達成できる軽量な代替手段に置き換えています。
</p>
</tldr>

Unreal Engine Vite はプロフェッショナルなゲーム開発のために作られ、現在開発中のタイトルを支えています。長期的な目標は、自社開発の独自エンジンに匹敵する CPU とレンダリングのスループットを備え、現行のコンソールハードウェアを見据えた性能・安定性・グラフィックスパイプラインの改良を続ける、進化し続けるモダンなエンジンです。

目標は反証可能なほど具体的です。**ミリ秒あたりの品質とシミュレーション規模で Epic の UE5 を上回り**、その両方で
AAA 向けの独自エンジンと競争力を持つことです。ミリ秒あたりの品質は [パフォーマンス目標](Performance-Targets.md)
と [UE4 と UE5 のコスト分析](UE4-Versus-UE5-Cost-Analysis.md) が測定しています。シミュレーション規模は
[物理](Physics-Cube-Bench.md) と [キャラクター](400-Characters-CMC-Bench.md) のベンチマークが測定しています。現時点で Vite が勝っていない点については、このマニュアルでそう明記します。

## 設計上の論点

Epic の Unreal Engine 5.7 と 5.8 は、Lumen、Nanite、仮想シャドウマップ、Temporal Super Resolution、Chaos を用いて、PlayStation 5 上で 720p〜1080p の動的内部解像度によりおよそ 60 FPS を目標としています。これは、このエンジンで出荷されたタイトルが実際に示している水準です。

仮想化のアプローチ、つまりジオメトリ・シャドウ・テクスチャの仮想化と再構成された解像度は、処理・ストリーミング・メモリのオーバーヘッドを増やします。時間的再構成、デノイズ、確率的サンプリングは、ノイズ、ゴースト、不安定さ、ブラーをもたらします。Substrate、GPU Scene、RDG、重いシェーダーモデル、そして全般的な機能拡張は、UE4 と比べてレンダラーの基本オーバーヘッド、シェーダーパーミュテーション数、バイトコードサイズ、PSO 数、コンパイル時間、キャッシュサイズを増やします。Chaos 以外にも、より重いシーン管理、GPU Scene のアップロード、Lumen の更新、Nanite のストリーミング、VSM の無効化、World Partition、レンダースレッドと RHI の負荷によって CPU コストが増加しています。

一方で、ハードウェアは逆方向に進んでいます。Nintendo Switch 2 は 7〜8 年の製品寿命が見込まれる形で発売されました。PS5 よりかなり非力な携帯機は、Valve の Steam Deck や Steam Machine を含め、いまや主流のセグメントです。AI 需要によりハードウェアの価格は上昇しています。こうした状況では、UE5 のパフォーマンス目標は実際にゲームが出荷されるマシンとますます噛み合わなくなっており、そのレンダリングスタックは大衆向けハードウェアでの持続的なゲーム開発よりも、映像制作、バーチャルプロダクション、ハイエンド PC に向いていると言えます。

Vite は逆の立場を取ります。コンシューマー機クラスのハードウェアで、高いネイティブ解像度のまま厳格なフレームタイム予算を守りつつ、高いビジュアル品質を優先します。

> レイトレーシング GI、レイトレーシング反射、テッセレーションを使った Vite のシーンは、レイトレーシングも Lumen も
> Nanite もテッセレーションも一切使わない UE 5.7 の同一シーンを上回る性能を発揮します。これは RTX 4080 Super と
> RDNA2 の RX 6700（PS5 相当）での 4K ネイティブ、そして Steam Deck のハードウェアでのネイティブ解像度で成り立ちます。
>
{style="note"}

## Vite の構成要素

Vite は NvRTX 4.27 Caustics のフォークとして始まりました。このブランチは Epic の標準 4.27 ブランチに対して、DX12、レイトレーシング、レンダリングの改良に加え、DLSS、NVIDIA Reflex、改良されたデノイザー、そして DDGI でライティングされたレイトレーシング反射を含む包括的なレイトレーシング対応を追加したものです。

このベースの上に、次のものを取り込んでいます。

- Epic の UE 4.27 Plus ブランチを完全にマージ。
- NVIDIA の NvRTX 5.0 ブランチをマージ。
- AMD のエンジンブランチのレンダリング機能を統合。
- UE 5.0 から 5.8 世代までの 300 件を超えるバックポートがリリースブランチにあり、内部のステージングブランチでは
  1,200 件以上を統合済み。

統合作業は Unreal Engine のソースに精通したエンジンプログラマーが行っています。適切なコードガードを用い、シェーダーパーミュテーションを管理し、取り込んだ UE5 の各変更を機械的にマージするのではなく、Vite のコードベースに合わせて手作業で適応させています。

PhysX と、DDGI と SSGI を組み合わせたライティングパイプラインを備えた Vite は、*The Finals* のローンチに使われた独自の Unreal Engine ビルドによく似た構成になっています。

## 主な機能

**[動的 DDGI](DDGI-Dynamic.md)。** Lumen に代わる、ノイズのないグローバルイルミネーションです。ソフトウェア Lumen
より高品質なバウンスと少ない光漏れを実現し、バウンス品質はハードウェア Lumen と同等で、フレームレートは一般に約
2 倍です。DDGI の実装は Metro Exodus、Overwatch 2、The Finals、Control、The Witcher 3、Warhammer 40,000: Darktide、DOOM: The Dark Ages、Indiana Jones and the Great Circle、007 First Light、Ghost of Yotei、そして Switch 2 版を含む
Star Wars Outlaws で出荷されています。

**[静的 DDGI](DDGI-Static.md)。** ほぼ一瞬で終わるベイク、従来のベイクライティングより高精度なバウンス、動くオブジェクトへのより良いカバレッジを備えたベイクモードで、レイトレーシング非対応の GPU でも利用できます。

**[PhysX 3.4](PhysX.md)。** 安定しており商用実績があり、Vite では新しい Clang でビルドできるよう更新して、コンパイラ最適化による確かな性能向上を得ています。社内のストレステストでは、物理がボトルネックとなるシナリオで
Chaos は PhysX より 5 倍以上遅くなっています。

**[RTXDI](RTXDI.md)。** MegaLights よりノイズの少ない代替手段です。UE 5.1 以降の NvRTX ブランチにある Lumen 統合版ではなく、スタンドアロン版を採用しています。

**[テッセレーション](Tessellation.md)。** Nanite のオーバーヘッドなしに、距離とディスプレイスメントに基づくジオメトリディテールを実現します。

**[レイトレーシング一式](Ray-Tracing.md)。** 反射、アンビエントオクルージョン、シャドウ、スカイライト、半透明、コースティクス、直接光、ピクセル単位のレイトレーシング GI、パストレーシング。Black Myth: Wukong のフルレイトレーシングモードと同じ、NVIDIA の RTX の技術の系統です。

変更点の全一覧は [リリースノート](Release-Notes.md) を参照してください。

## UE4 は非推奨のコードベースではないのか

もっともな疑問ですが、答えは「Unreal Engine 4 は最近の AAA タイトルでも使われ続けている」です。Final Fantasy VII Rebirth（4.26、2024 年）、Stellar Blade（4.26、2024 年）、Days Gone Remastered（4.11、2025 年）、Delta Force（4.22、2026 年）、Mortal Kombat 1（4.27、2023 年）、Mario &amp; Luigi: Brothership（4.26、2024 年）、Princess Peach: Showtime!（4.26、2024 年）、Pikmin 4（4.26、2023 年）、Square Enix の Dragon Quest VII Reimagined
（4.27、2026 年）、そして発売予定の Final Fantasy VII: Revelation（4.27、2027 年）です。いずれも PhysX を使って出荷されています。

これらのタイトルは、特定の機能を維持し、品質とパフォーマンスの目標を満たすために UE4 にとどまっています。UE4 は
4.27 Plus ブランチを通じて大手スタジオから更新を受け続けており、任天堂のプラットフォームでは今も優先されています。

Vite の方針は、4.27 を凍結された遺物として扱うのではなく、このコードベースを改良し続けることです。コアシステムの最適化、レンダリングコアの近代化、UI の改善、ツールチェーンの更新を進めます。ベースバージョンを選んだ技術的な理由は [なぜ NvRTX 4.27 なのか](Why-NvRTX-427.md) を参照してください。
