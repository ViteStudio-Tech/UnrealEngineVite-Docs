# 動作環境

<tldr>
<p>
Windows 10 または 11（x64）。レイトレーシング対応 GPU を推奨しますが必須ではありません。
<a href="DDGI-Static.md">静的 DDGI</a> とラスタライズのパスは、DXR に一切対応していないハードウェアでも動作します。動的 DDGI は GTX 1060 6&nbsp;GB クラスの GPU まで性能を落として動作するよう設計されています。
</p>
</tldr>

Vite の要件は 2 種類あります。エンジンで作ったコンテンツを *実行する* ための要件と、*エンジン自体をビルドする*
ための要件です。両者は大きく異なり、後者のほうがはるかに重い要件です。

## Vite のコンテンツを実行する

Vite は幅広いハードウェアに対応できるよう明確に設計されています。そもそも Lumen ではなく DDGI を選んだ理由がそこにあります。

| | 最小 | 推奨 |
|---|---|---|
| OS | Windows 10 x64 | Windows 11 x64 |
| GPU（レイトレーシングなし） | DirectX 11 対応の任意の GPU | &mdash; |
| GPU（動的 DDGI） | GTX 1060 6&nbsp;GB または任意の RDNA2 | RTX 2060 / RX 6600 以上 |
| GPU（レイトレーシング一式） | RTX 2060 / RX 6600 | RTX 3070 / RX 6700 XT 以上 |
| VRAM | 6&nbsp;GB | 8&nbsp;GB 以上 |

動的 DDGI は GTX 1060 6&nbsp;GB クラス以上の GPU で動作します。それ未満、またはレイトレーシング非対応の GPU では、[静的 DDGI](DDGI-Static.md) を使用してください。静的 DDGI はイラディアンスをプローブボリュームにベイクするため、実行時のレイトレーシングコストがかかりません。

### テスト用ハードウェア

Vite が継続的にベンチマークとチューニングを行っている構成です。以下のテスト用ハードウェアは、このフォークの主要開発者が所有しています。

CPU の FPU 関連の作業と GPU コンパイラ関連の作業は、別々のマシンで行います。4700S は Series X と比べて（主に FPU が）さらに削減された Zen 2 で、PhysX 3.4 などの FPU カーネルを PS5 の CPU 上と同じ条件で計測するために使います。RX 6700 は PC 向け RDNA2 のコンパイラ代替機であり、PS5 の RDNA2 とは依然として差があります。4700S/4800S の GPU は無効化されています。BC-250 の GPU は動作しますが、Windows 上では動きません。詳細は [PS5 CPU の FPU](PS5-CPU-FPU.md)
を参照してください。

| ベンダー | ハードウェア | 意義 |
|---|---|---|
| AMD | 4700S（Zen 2、iGPU 無効） | PS5 CPU の FPU の代替（FMA パイプ 1 本）。PhysX 3.4 |
| AMD | RX 6700（RDNA2） | PS5 向けの PC RDNA2 コンパイラ・スループットの代替 |
| AMD | Steam Deck LCD Van Gogh（RDNA2） | 携帯機クラス |
| AMD | RX 9060 XT（RDNA4） | ミドルクラス GPU |
| NVIDIA | RTX 2060（Turing） | ハードウェア RT と DLSS の下限 |
| NVIDIA | RTX 3060（Ampere） | Steam ハードウェア調査で最も多い GPU に近い |
| NVIDIA | RTX 4080 Super（Ada Lovelace） | 4K ネイティブキャプチャの上限リファレンス |

テストは 4K ネイティブのモニターまたはテレビ（RX 6700 / RTX 4060 以上）で行うのが最も有意義です。Vite の主張の核心は、低い内部解像度からのアップスケーリングではなく、ネイティブ解像度を維持することにあるからです。

自分のハードウェアでの結果（デモなど）を紹介したい場合は、Discord の `#showcase` チャンネルでテストの調整を行っています。

## ソースからエンジンをビルドする

ビルドは CPU、RAM、ディスクに大きく依存します。以下は厳密な下限ではなく、実用上の目安です。

| | 実用上の最小 | 快適な構成 |
|---|---|---|
| CPU | 6 コア / 12 スレッド | 16 コア / 32 スレッド以上 |
| RAM | 24&nbsp;GB | 32&nbsp;GB |
| ストレージ | 空き容量 50&nbsp;GB の SATA SSD | Windows 向けのツリー全体で空き容量約 140&nbsp;GB の NVMe SSD |
| OS | Windows 10 x64 | Windows 11 x64 |

依存関係、中間ファイル、ビルド済みエディタを含む Unreal Engine 4.27 のソースツリーは非常に大きくなります。100 GB を大きく超える容量を見込んでください。インストール済みビルドも作成する場合は
`LocalBuilds\Engine\Windows\` に 2 つ目のコピーが書き込まれるため、さらに容量が必要です。HDD でも動作しますがすべての手順が苦痛になるため、SSD を使用してください。

コンパイル時間はコア数にほぼ比例して短縮されます。Ryzen 9 9950X3D でのフルビルドはおよそ 15 分です。対象としないプラットフォームを除外し、オプションのコンテンツを削ることで、時間とディスク容量の両方を大きく節約できます。[デブロートガイド](Debloat-Guide.md) と [ソースからのビルド](Build-From-Source.md) で説明しているセットアップのプリセットを参照してください。

特定のコンパイラと SDK も必要です。これは任意ではなく、[ツールチェーン要件](Toolchain-Requirements.md) で別途説明しています。
