# Crash Bandicoot: Timetwister

<tldr>
<p>
Crash Bandicoot 3: Warped の Tomb Wader のレベルを Unreal Engine 4.26 で再現した、コミュニティによるリメイクです。ライティングのシーンではなく、完全なゲームプレイのレベルです。
</p>
</tldr>

<img src="CrashBandicootRemake.png" alt="エンジン上で動作する Tomb Wader のレベルのリメイク" border-effect="line"/>

*ライティングのシーンではなく完全にプレイできるレベルなので、フレームのコストの傾向が実際のプロジェクトに近くなります。*

## ソース

[dyanikoglu/CrashBandicoot-Timetwister](https://github.com/dyanikoglu/CrashBandicoot-Timetwister)

## ここにある理由

このセクションのプロジェクトの大半は技術のデモで、1 つのレンダリングの機能を見せるためのシーンです。これは移動、コリジョン、障害物、収集物、カメラのシステムを備えたプレイできるレベルで、性質の異なる基準になります。

役に立つ点は 2 つです。

- **ゲームプレイの形をしたプロファイリング。** 実際のレベルには、ライティングのシーンにはないフレームのコストの傾向があります。アクターのティック、アニメーション、コリジョンのクエリ、ゲームプレイのロジックが描画と競合します。それがほとんどのプロジェクトの実際の姿です。[プロファイリング](Profiling.md) を参照してください。
- **4.x で十分であることの実証。** スタイライズドなプラットフォーマーは、UE5 の目玉機能がたいした価値を加えずにコストだけを加え、4.27 の低い基本コストのほうが良い取引になるジャンルそのものです。[なぜ NvRTX 4.27 なのか](Why-NvRTX-427.md) を参照してください。

## バージョンについて

<note>
このプロジェクトの対象は 4.27 ではなく Unreal Engine 4.26 です。Vite で開くと、エンジンのバージョンの変換を求められます。アセットと API の違いをいくつか解決する必要があると考えてください。4.26 と 4.27 の差は小さいものの、ゼロではありません。
</note>

UE5 から移る場合は Asset Downgrader が必要なので、それに比べればはるかに簡単な変換です。[UE5 からの移行](Migrating-From-UE5.md) を参照してください。

## ライセンス

これはサードパーティのコミュニティのプロジェクトで、Vite の提供物ではありません。著作物のファンによるリメイクなので、アセットを再利用する素材としてではなく、学ぶための参考として扱ってください。条件はリポジトリを参照してください。
